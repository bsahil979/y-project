# Phase 3: shared causal HMM engine

`services/hmm_engine.py` fits StandardScaler only on the supplied training window, then a three-state Gaussian HMM with 500 iterations, tolerance 1e-4 and covariance floor 1e-3. Full covariance falls back to diagonal after failure/nonconvergence; high-dimensional inputs start with diagonal. Diagonal uses deterministic variance-state initialization and one additional deterministic restart if necessary. All attempts are recorded. Iteration-cap termination alone is never reported as convergence.

Canonical ordering uses realized volatility ascending, with higher realized mean return breaking ties. States are 0 Low-Vol/Bullish, 1 Neutral/Transition, 2 High-Vol/Stress. Return direction is a descriptive label, not a guarantee. The internal model and scaler/state mapping are persisted together; public probabilities and IDs use the canonical order.

Allocation and live regime detection use the same engine. MarketMind features refit every 21 observations on at most 504 past observations, with 126-observation warmup. Between refits, probabilities update by forward filtering. No future rows enter fitting, scaling or inference for an earlier feature. Warmup/failed fitting is explicitly unavailable with neutral code and missing probabilities. MarketMind's 14 input columns are unchanged; new models consume canonical regime_code. Legacy saved models receive their original +1/0/-1 encoding at inference, with a revalidation flag because the signal source changed. Posterior probabilities are diagnostics, not added input columns. Live fetching uses three years to retain sufficient history after indicator warmup.

Pipeline market_regime and metadata.hmm expose convergence, iterations, covariance type and state probabilities. regime_allocation exposes the same diagnostics plus forecast probabilities. Restored research delivery validates the snapshot and source hashes, and correctly marks preserved results stale after source changes. The old reproduction files are unchanged.

Validation: rerunning the original 70 training endpoints produced 70 converged fits, zero iteration-cap failures (56 full and 14 diagonal). See research/phase3_convergence_check.json. Reproduce from analytics-engine with `python -m research.check_hmm_convergence`. This checks fitting convergence only; it does not regenerate backtest performance or establish out-of-sample model quality.
